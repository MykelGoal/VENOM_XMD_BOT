# 🎬 CapCut — "Drop-Down Text" Effect (slides in → shows → slides back up)

The look: a text label slides DOWN into view, sits ~1.5s, then slides UP and
disappears. Clean, fast, doesn't crowd the screen. Great for step labels.

There are 2 ways — EASY (built-in animation) and PRO (with a bar behind it).

---

## ⭐ EASY WAY (2 min) — use built-in In/Out animations

1. Move the playhead to where the label should appear.
2. Bottom toolbar → **Text → Add text** → type your label (e.g. `Step 1: Star ⭐ + Fork`).
3. Drag the text to the position you want (top third looks best for this effect).
4. Keep the text SHORT on the timeline — about **1.5–2 sec** only. (Drag its right edge in.)
5. Tap the text → **Animation**.
6. **In** tab → choose one that moves DOWN:
   - `Drop` / `Slide down` / `Fall` — pick whichever shows an arrow moving down.
   - Set the In duration to about **0.4s** (drag the little slider).
7. **Out** tab → choose one that moves UP:
   - `Rise` / `Slide up` / `Float up`.
   - Set Out duration to about **0.4s**.

✅ Result: text drops in, holds, slides up and leaves. Repeat for each step label.

---

## 🔥 PRO WAY — add a BAR/BOX behind the text (the "drop-down panel" look)

This is the polished version where a colored bar drops with the text on it.

1. **Make the bar:** bottom toolbar → **Overlay → Add overlay** → add a plain
   image/color block. (Fastest: keep a solid black or green PNG rectangle in your
   gallery. Or use **Text → Add text**, type a few spaces, then in the text
   **Style → Background** turn ON a background color — that gives you a bar.)
2. Size the bar into a thin strip near the top. Set its length to ~1.5–2s.
3. Tap the bar → **Animation → In: `Slide down`** (0.4s), **Out: `Slide up`** (0.4s).
4. Now add your **Text** on top of the bar (same position, same length).
5. Give the TEXT the SAME animations: **In: Slide down**, **Out: Slide up**, same 0.4s.
6. Line up the bar and text so they start and end at the exact same time
   (drag both to align on the timeline).

✅ Result: a bar + text drop in together, hold, then slide up together. Very pro.

---

## ⏱️ TIMING RULE (fixes your "it takes too long" problem)
- In animation: **0.3–0.4s**
- Text visible (hold): **1.2–1.8s**  ← keep it short!
- Out animation: **0.3–0.4s**
- Total per label ≈ **2–2.5s**. Then it's GONE, screen stays clean.

## 💡 TIPS
- Use the SAME animation for every label = consistent, intentional, pro.
- White text + black/green background bar = readable on any footage.
- Don't overlap two labels — one drops out before the next drops in.
- Copy-paste the finished bar+text and just retype it for the next step
  (keeps timing + style identical). Tap it → **Copy** → paste → move → edit words.
